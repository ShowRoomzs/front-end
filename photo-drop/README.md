# 실물 사진 넣는 곳 — 저장 지시서

**총 31장.** 아래 이름 그대로 저장해서 지정된 폴더에 넣으면 된다.

```
photo-drop/
├─ posts/       ← 게시물 사진 24장 (post-01.jpg ~ post-24.jpg)
└─ profiles/    ← 프로필 사진 7장  (jenny.jpg 등)
```

- **확장자는 `.jpg`로.** png·webp·heic로 받았으면 그대로 넣어도 된다(내가 변환한다)
- **비율 · 용량 · 해상도는 안 맞춰도 된다.** 원본이 클수록 좋다. 크롭과 압축은 내가 한다
- **이름을 못 맞추겠으면** 아무 이름으로 넣고 "몇 번 자리"인지만 알려주면 배치한다
- **전부 안 채워도 된다.** 넣은 것만 교체되고 나머지는 지금 이미지가 남는다

## ★ 표시의 뜻

**★ = 홈 피드에서 전체 너비로 크게 뜬다.** 14장.
표시 없음 = 게시물 상세로 들어가야 보인다. 10장.

공구 게시물은 홈 카드에 큰 사진이 안 나오기 때문이다(배지 → 제목 → 본문 → 90×90 상품
썸네일 → 좋아요 순으로만 그린다). **시간이 부족하면 ★부터 채울 것.**

# 사진에 맞춰 내가 고치는 것

사진이 데이터를 이긴다. 들어온 사진을 보고 아래를 사진 쪽으로 맞춘다.

- **상품 이름** — 사진이 밤이면 "앰플"을 "밤"으로 바꾼다
- **공구 제목 · 게시물 본문** — 바뀐 상품 이름에 맞춰 다시 쓴다
- **옵션 이름** — "30ml / 50ml"을 "50g / 100g"처럼
- **상품 사진** — 형태가 달라지면(튜브 → 단지) 그 상품 이미지를 다시 생성한다.
  홈 공구 카드에 90×90으로 뜨는 게 이 이미지라, 이름만 바꾸고 두면 어긋난다
- **마이 > 문의 내역**에 박힌 상품명 2곳(`data/support.ts`)

## 이름이 바뀌어도 절대 안 건드리는 것

옵션 시연이 이번 데모의 핵심이라, **구조 다섯 가지는 그대로 둔다.** 이름만 갈아 끼운다.

| 무엇을 보여 주나 | 지금 담당 상품 |
| --- | --- |
| 옵션 없음 (수량만) | 배리어 크림 · 아이팔레트 |
| 1단 옵션 | 세럼(용량 2) · 선크림(타입 2) · 헤어 에센스(향 3) |
| **2단 단계적 잠금 + 품절 행** | 시카 앰플 (구성 3 × 용량 2, 50ml 품절) |
| **12개 목록 → 6줄에서 스크롤** | 립틴트 (12색, 2개 품절) |
| 전체 품절 → 구매 잠김 | 두피 스케일러 |

그래서 예를 들어 **립틴트 자리에는 색이 여러 개인 상품**이 와야 한다.
색 개념이 없는 제품(크림 등)으로 바꾸면 12색 스크롤을 보여 줄 데가 없어진다.

# 사진 구하는 곳

**Unsplash** (unsplash.com) · **Pexels** (pexels.com). 둘 다 상업적 사용 무료, 출처 표기 의무 없음.
**검색은 영어로** 해야 결과가 훨씬 많다.

| 필요한 것 | 검색어 |
| --- | --- |
| 스킨케어 세트 | `skincare set flatlay`, `beauty routine trio` |
| 클렌저 · 선크림 | `cleanser and sunscreen`, `white skincare tubes minimal` |
| 세럼 단품 | `serum bottle closeup dark background` |
| 제형 · 텍스처 | `cream texture`, `serum drop`, `cosmetic swatch` |
| 성분표 | `cosmetic label closeup`, `ingredient list` |
| 크림 단지 | `cream jar minimal shadow`, `single skincare jar` |
| 립 스와치 | `lipstick swatches arm` |
| 아이팔레트 | `eyeshadow palette top view`, `autumn makeup flatlay` |
| 헤어 | `hair care bottles dark`, `salon hair products`, `healthy hair closeup` |
| 인물 | `woman portrait natural light`, `korean woman portrait` |

## 쓰면 안 되는 것

- **연예인 · 인플루언서 사진** — 초상권 문제가 그대로 남는다
- **실제 브랜드 로고가 읽히는 제품** — 데모에 없는 브랜드가 화면에 뜬다. 라벨이 흐리거나 무지인 것
- 구글 이미지에서 그냥 가져온 사진 — 출처가 불분명하다

지인 사진은 **동의를 받고** 넣을 것.

# 참고 규격 (안 맞춰도 된다)

| 종류 | 크기 | 비율 |
| --- | --- | --- |
| 게시물 | 1080 × 1350 | **4:5 세로** |
| 쇼룸 프로필 | 600 × 600 | 1:1 |
| 사용자 프로필 | 400 × 400 | 1:1 |

게시물이 4:5인 게 중요하다 — 카드 높이를 이 비율로 잡는다. 다른 비율은 내가 4:5로 자르는데,
**세로로 여유 있는 사진**일수록 잘라도 손해가 적다. 가로로 긴 사진은 양옆이 많이 날아간다.

여섯 쇼룸의 **배경색이 서로 달라야** 피드에서 구분된다. 지금 배분이 이미 갈려 있으니
베이지(제니) · 화이트(하루) · 다크(미아) · 가을 웜톤(소연) · 딥그린(다은) · 그레이(윤)만
지켜 고르면 여섯 사람이 다른 계정으로 보인다.
