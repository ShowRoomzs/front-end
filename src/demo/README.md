# 데모 모드 — 창업지원단 미팅용 빌드

앱이 **서버를 전혀 부르지 않고** 내장 데이터와 이미지만으로 도는 모드다.
네트워크가 나쁜 장소에서도 시연이 끊기지 않고, 아직 서버에 없는 공동구매 게시물까지 보여 줄 수 있다.

---

## 빌드하기

```bash
cd front-end
eas build --platform ios --profile demo     # 40~60분 (iOS는 소스 빌드라 길다)
eas submit --platform ios --latest          # TestFlight 처리 10~30분
```

`eas.json`의 `demo` 프로필이 `EXPO_PUBLIC_DEMO_MODE=true`를 심는다. **운영 프로필(`production`)은 손대지 않았다.**

> ⚠️ EAS 환경변수가 번들에 안 실리는 사고에 대비해 `src/demo/config.ts`에 `FORCE_DEMO` 스위치를 뒀다.
> 빌드했는데 데모 데이터가 안 보이면 그 값을 `true`로 바꾸고 다시 빌드하면 된다.

로컬 확인은 이렇게 한다. **개발 클라이언트가 필요하다** — 카카오·네이버 로그인 네이티브 모듈이
들어 있어 Expo Go로는 뜨지 않는다.

```powershell
# PowerShell (Windows)
$env:EXPO_PUBLIC_DEMO_MODE="true"; npx expo start --dev-client --clear
```

```bash
# bash / zsh
EXPO_PUBLIC_DEMO_MODE=true npx expo start --dev-client --clear
```

`EXPO_PUBLIC_*`는 **번들할 때 값이 박히므로**, 값을 바꾼 뒤에는 `--clear`로 Metro 캐시를 비워야
반영된다. 매번 넣기 번거로우면 `.env`에 `EXPO_PUBLIC_DEMO_MODE=true` 한 줄을 넣고 쓰다가
지워도 된다.

### 릴리스 번들까지 확인하려면

개발 서버는 이미지를 Metro가 http로 내려 준다. 실제 빌드는 앱 안에 박힌 파일을 읽으므로
**경로를 만드는 방식이 다르다**(`Image.resolveAssetSource`). iOS 빌드에 한 시간 쓰기 전에
안드로이드 릴리스 APK로 같은 경로를 15분 만에 확인할 수 있다.

```bash
eas build --platform android --profile demo-apk
```

APK 링크를 받아 안드로이드 기기에 바로 설치하면 된다. 여기서 사진이 정상으로 뜨면
iOS에서도 뜬다.

### 상품과 쇼룸

지어낸 상품명보다 아는 제품이 빨리 읽힌다. 화면을 보는 사람이 "이거 내가 쓰는 건데"라고
알아보는 순간 플랫폼이 돌아가고 있다는 인상이 생긴다.

| 쇼룸 | 다루는 것 | 공구 |
| --- | --- | --- |
| 제니의 뷰티룸 | 아누아 세럼 · 토너 | D-3 |
| 하루 코스메틱 | 세타필 크림 · AHC 로션 | D-5 (광고) |

| 다은의 헤어살롱 | 엘라스틴 샴푸(품절) · 케라시스 트리트먼트 | D-7 |

> **브랜드 이름과 제품 사진만 실제**를 쓰고, 판매자 정보(사업자등록번호 · 주소 · 전화)는
> 전부 지어낸 값이다. 실제 법인 정보를 넣으면 그 회사가 입점한 것처럼 보이기 때문이다.
> 회사명도 `아누아 공식스토어 (데모)`처럼 데모임을 남겨 두었다.

### 옵션 시트 다섯 화면

이번 데모에서 제일 보여 줄 만한 부분이라, 상품이 바뀌어도 이 구조는 그대로 둔다.

| 화면 | 담당 상품 |
| --- | --- |
| 옵션 없음(수량만) | AHC 로션 |
| 1단 옵션 | 아누아 세럼 · 토너, 세타필, 폴메디슨 |
| **2단 단계적 잠금 + 품절 행** | 온더바디 바디워시 (향 3 × 용량 2, 500ml 품절) |
| **8줄 → 6줄에서 잘려 스크롤** | 케라시스 (구성 8, 2개 품절) |
| 전체 품절 → 구매 잠김 | 엘라스틴 샴푸 |

### 동작하는 것

팔로우 · 좋아요 · 장바구니 담기/수량/삭제 · 옵션 선택 · 문의 작성 · 검색 · 정렬 · 프로필 수정.
전부 메모리에만 쌓이므로 **앱을 껐다 켜면 처음 상태로 돌아온다** — 같은 시연을 반복할 때 오히려 편하다.

### 로그인 화면을 보여 주려면

마이 → 설정 → 로그아웃. 카카오·네이버 버튼은 **SDK가 실제로 뜨고**, 서버 검증만 데모가 통과시켜
다시 "수민"으로 들어온다.

### 사진을 갈아 끼우려면

`photo-drop/posts/`에 원본을 넣고 `scripts/build-demo-photos.py`의 `POSTS` · `PRODUCTS`에서
어느 자리에 쓸지 지정한 뒤 스크립트를 돌린다. 크롭 · 확대 · 압축은 스크립트가 한다.

```bash
python scripts/build-demo-photos.py
```

쇼룸 · 사용자 프로필 7장만 아직 `scripts/generate-demo-images.py`가 만든 생성 이미지다.

## 시연 동선 추천

1. **홈** — 공구 카드(D-3 배지 · 상품 묶음)와 일반 게시물이 섞인 피드를 내린다
2. 팔로잉 게시물을 다 내리면 **"새 게시물을 모두 확인했어요"** → 추천 피드로 이어진다
3. 공구 카드의 상품을 눌러 **상품 상세** — 갤러리 · 가격 · 탭 3개
4. **케라시스 상세정보 탭** — 한글 카피가 들어간 **실제 상세페이지**가 세로로 스크롤된다
5. **[구매하기]** → 온더바디 바디워시는 향을 고르기 전 용량이 잠기고, 500ml에 품절 딱지가 붙는다
6. 케라시스는 **구성이 8개**라 목록이 6줄에서 잘리고 스크롤된다
7. **엘라스틴 샴푸** — 상품 전체가 품절이라 구매 버튼이 잠긴 화면
8. **문의 탭** — 아코디언 · 비밀글 자물쇠 · 답변 대기 · 작성자 마스킹
9. **판매자 정보 탭** — 고시 표 · 배송/교환/반품 · 판매자 정보 3단 아코디언
10. **장바구니** — 공구별 묶음 · 무료배송까지 남은 금액
11. **쇼룸**(카드의 아바타 탭) — 프로필 · 진행 중 공구 고정 · 게시물 목록
12. **마이** — 프로필 · 주문 현황 · 메뉴 · 사업자 정보 푸터

## 데모가 끝나면

```
src/demo/                       폴더째 삭제
photo-drop/                     폴더째 삭제 (원본 사진)
scripts/build-demo-photos.py    삭제
scripts/generate-demo-images.py 삭제
eas.json                        "demo" · "demo-apk" 프로필 삭제
각 서비스의 IS_DEMO 분기         삭제 (19곳, 파일 끝 3줄씩)
```

서비스 파일에서 `realXxxService`를 다시 `export const xxxService`로 되돌리면 원래 상태다.

> ⚠️ **`src/demo/config.ts`의 `FORCE_DEMO`가 지금 `true`다.** 이 값이 켜져 있는 동안에는
> 어떤 프로필로 빌드해도 데모로 돈다. 운영 빌드 전에 반드시 `false`로 되돌릴 것.
>
> 데모 모듈이 정적으로 import돼 있어, 데모 모드가 꺼진 빌드에도 이미지 4MB가 함께 번들된다.
> 운영 빌드를 내보내기 전에는 위 순서대로 지우는 편이 좋다.
>
> **사진은 브랜드 공식 컷을 그대로 쓴 것이라 배포용이 아니다.** 미팅 시연용으로만 두고,
> 스토어에 올릴 빌드에는 반드시 걷어낼 것.
