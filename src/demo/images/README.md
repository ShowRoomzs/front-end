# 데모 이미지 — 파일명 목록

창업지원단 미팅용 데모 빌드가 쓰는 이미지다. **파일명을 이 표대로 맞춰 이 폴더에 넣으면**
코드가 그대로 집어간다. 전부 **`.jpg`**.

없는 파일은 개발 중에 화장품 스톡 사진으로 채워 둔다 — **한 장도 안 넣어도 빌드는 깨지지 않고
화면도 채워진다.** 받는 대로 같은 이름으로 덮어쓰면 된다.

> 투자자 미팅이므로 **타사 브랜드 제품 사진보다 직접 촬영했거나 사용 허락이 있는 이미지**가 안전하다.

## 2순위 — 있으면 더 진짜 같아진다 (33장)

| 폴더 | 파일 | 규격 | 내용 |
| --- | --- | --- | --- |
| `products/` | 위 10개 슬러그의 `-2.jpg` | 정사각 1000px↑ | 두 번째 컷 (질감 · 사용 장면) |
| `products/` | 위 10개 슬러그의 `-detail.jpg` | 세로 1080×2000 내외 | 상세페이지 이미지 |
| `posts/` | `post-13.jpg` ~ `post-24.jpg` | 4:5 1080×1350 | 추가 게시물 사진 |
| `user/` | `me.jpg` | 정사각 400px↑ | 데모 유저(수민) 프로필 |

예: `cica-ampoule-2.jpg`, `cica-ampoule-detail.jpg`

---

## 이 폴더를 지우는 법

데모가 끝나면 `src/demo/` 전체와 `eas.json`의 `demo` 프로필을 지우면 된다.
데모 코드는 `EXPO_PUBLIC_DEMO_MODE`가 켜져 있을 때만 동작하므로 운영 빌드에는 영향이 없다.
